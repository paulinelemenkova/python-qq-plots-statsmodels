# Quantile-Quantile (Q-Q) Plots with Python and statsmodels

Python script drawing quantile-quantile (Q-Q) plot subplots to check distributional assumptions with statsmodels, on Mariana Trench data. Reusable statistical-graphics example.

## Scripts

- `qqplots_subplots_2_3.py`

## Data

- `Tab-Morph.csv`

## Requirements

Python 3 with `matplotlib`, `numpy`, `pandas`, `scipy`, `seaborn`, `statsmodels`.

```
pip install matplotlib numpy pandas scipy seaborn statsmodels
```
